# Fix Summary — 2026-08-06

## Root Causes (verified live)

**1. Graph expansion dead — `KeyError: 'name'` on every call**  
   - `_EXPAND_CYPHER_TMPL` contains literal Cypher map `{name: n.name, embedding: n.embedding}`  
   - `expand()` used `.format(hops=2)` → Python parsed `{name:` as a replacement field  
   - Expansion silently returned [] for the entire project's lifetime  
   - **Fix:** `.replace('{hops}', str(hops))` instead

**2. Chunk `text` never persisted — Neo4j had 0/14 chunks with text**  
   - No-entity branch omitted `c.text = $text` and the param itself  
   - Entity branch passed `text=chunk["text"]` (uncommitted local change)  
   - Search/chat pulled text from Pinecone metadata, so this was masked  
   - **Fix:** both branches now pass `text=chunk.get("text", "")`

**3. Fake embeddings silently corrupted Pinecone — 12/26 vectors fabricated**  
   - `safe_embed_*` fell back to sha256-derived vectors on any Cohere failure  
   - Indistinguishable from real embeddings → search returned confident nonsense  
   - Trial key exhausted monthly quota (1000 calls/month)  
   - **Fix:** raise `EmbeddingUnavailable` immediately; retry only transient per-minute limits

**4. Silent swallowing masked the quota failure**  
   - `vectorstore.query` caught all exceptions → returned `[]`  
   - Chat rendered as "no information found" instead of a service error  
   - **Fix:** propagate `EmbeddingUnavailable` as HTTP 503 with actionable message
